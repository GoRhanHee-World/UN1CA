# Samsung App Lock on the S20 series

Partial cherry-picks from MinsOS `ea15a25e` (package installation) and `99722b9a`
(One UI 9 Settings gate), with the CoreRune gate from `9e75fb32`.
Only x1q, y2q and z3q on Android 17 or newer are enabled.

The Samsung-signed AppLock 3.0.0 APK and its exact privileged permission allowlist
are included under `files/system`. The build checks both hashes before enabling
the framework. `fetch_applock.sh` can restore the pinned files and checks the
APK certificate and package identity with the upstream `apk_cert.py` helper.
Installation metadata is generated by UN1CA's standard helpers.

App Lock authenticates access to apps in the existing user profile. It does not
create a separate app/data container. The Settings entry remains unavailable to
secondary users and when the AppLock package is absent.

Upstream: https://gitlab.com/minsos1/MinsOS (GPL-3.0).
Samsung APK source and pinned hashes: `fetch_applock.sh`.
